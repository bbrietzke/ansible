== My Ansible Pipeline
This is the copy of the ansible pipeline that I use to maintain my home networking infrastructure. 

My personal infrastructure has grown a bit over time.  It's a four node Kubernetes cluster (one control plane and three workers), a handful of OpenClaw agent boxes, some machines in the basement and the apartment, and a couple of Raspberry Pis (octopi and retropie).

All of the Ubuntu machines are loaded with Ubuntu 26.04 LTS.

[NOTE]
====
All of this works for me and may not work for you.  You can certainly take this and do your own thing with it if you want.

Just don't blame me if it doesn't work the way you expect.
====

== Running the Playbooks
Everything is driven through the Makefile in the root of the directory.  For example:

[source,bash]
make update EXE_OPTIONS=--ask-become-pass

or

[source,bash]
make kube-update EXE_OPTIONS=--ask-become-pass

The full list of commands, playbooks and what they do is in link:index.md[index.md].

== Directory Layout
I try to follow the ansible best practices that can be found at https://docs.ansible.com/ansible/latest/tips_tricks/sample_setup.html[Sample Ansible Setup], with the playbooks in the root of the directory, the inventories in `inventories` and the roles in `roles`.
